CREATIVE COMPASS — SHAREABLE EDITION with DESIGN PLAYGROUND
=====================================================
Updated edition: November 2026

WHAT'S INSIDE
  index.html              Website (runs fully in the browser)
  banner.jpg              Your Creative Compass branding / illustration
  README.txt              These instructions

FEATURES
  My Interests: capture what you enjoy and notice your recurring themes
  Idea Library: explore 30 project/income ideas and save favorites
  Parking Lot: save thoughts without committing
  Experiments: track small tests and reflections
  Design Playground: 56 hand-authored prompts + 6 constraints = 336 combinations;
                     choose a skill, difficulty and optional time budget;
                     bookmark challenges, record practice, add notes,
                     turn challenges into experiments
  Reflections: journal prompts and an open notebook
  Privacy & Backups: local-only storage, JSON backup and restore

PUBLISH FREE
  1. Go to https://pages.cloudflare.com/ and create a free account.
  2. Workers & Pages > create a Pages project > drag-and-drop upload.
  3. Upload the contents of this ZIP (or the ZIP, if the upload tool accepts it).
  4. Share your resulting *.pages.dev link.

IMPORTANT PRIVACY NOTE
  This version has no accounts, database, analytics or third-party scripts.
  Personal notes are stored in browser localStorage, separately for each
  browser profile and website origin. Other people using the same browser
  profile can view the entries. Backups are not encrypted. Users should
  export private backups regularly, especially before clearing site data
  or changing devices. Data does not automatically synchronize.

UPDATING AN EXISTING SITE
  Upload these files to the SAME site and hostname, keeping the same URL.
  The app intentionally uses the ORIGINAL storage key
  creative-compass-shareable-v1, so previous locally saved interests, notes,
  ideas and experiments remain available in that browser. Old backups can
  still be imported. Save a backup before any site update.

LOCAL PREVIEW
  Open the standalone Creative_Compass_Shareable_App.html in a browser.
  Local storage may behave differently on file:// URLs; a hosted HTTPS
  website is recommended for consistent save behavior.

The prompts are original and generated in your browser without AI services
or extra subscription costs. No deadline, streak, or mandatory schedule.
