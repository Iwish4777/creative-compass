07 / Your data

Private notes, practical backups.

No account, no central database, and no information sent back to the creator. The app runs in your own browser.

How your data is kept

Your interests, saved projects, parking-lot notes, experiments, and reflections are stored in this browser's local storage, under this website address.

Different people on their own devices and browser profiles have separate storage. Anyone with access to the same device and browser profile may see the entries.

Private browsing, browser cleanup, changes of website address, or deleting site data can erase locally saved information. Your records do not automatically sync across devices.

Backups are plain-text JSON files, not encrypted. Keep them in a private location. Anyone who obtains one can read what it contains.

Checking browser storage…

Save or restore a backup

Export your progress whenever you like. You can restore the same backup later, including on another device.

Restoring replaces entries already saved in this browser. Export the current entries first if you want to keep them.

Clearing this app does not delete copies of previously downloaded backups.

Built for a small first release

This version is free to use, has no logins or shared cloud storage, and does not require paid services for its features. If user accounts are added someday, the database would need real per-user access rules, secure authentication, consent/privacy information, and a migration path for these backups.
